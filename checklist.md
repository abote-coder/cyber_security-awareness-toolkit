Cybersecurity Personal & Academic Hygiene Checklist
This checklist outlines essential daily and routine security practices designed to protect institutional assets, personal accounts, and sensitive data from common cyber threats.
1. Password Security
* [ ] Use a unique, strong password for every individual account (minimum 12 characters).
* [ ] Combine uppercase letters, lowercase letters, numbers, and symbols.
* [ ] Avoid using easily guessable personal information (e.g., birthdays, pet names).
* [ ] Utilize a trusted password manager to securely store and generate credentials.

## 2. Multi-Factor Authentication (MFA)
* [ ] Enable MFA on all institutional accounts, email portals, and financial services.
* [ ] Prefer app-based authenticators (e.g., Microsoft Authenticator, Google Authenticator) or hardware security keys over SMS verification codes.
* [ ] Keep backup recovery codes in a secure, offline location.

## 3. Device & System Security
* [ ] Enable automatic updates for operating systems, web browsers, and productivity applications.
* [ ] Ensure active antivirus and anti-malware software is running with up-to-date definitions.
* [ ] Always lock your device screen (e.g., `Win + L` or `Cmd + Ctrl + Q`) whenever you step away.

## 4. Safe Browsing & Network Habits
* [ ] Verify HTTPS encryption and website security certificates before entering credentials.
* [ ] Avoid clicking unsolicited links or downloading attachments from unknown senders.
* [ ] Always connect via a secure Virtual Private Network (VPN) when using public or untrusted Wi-Fi networks.

## 5. Incident Response & Reporting
* [ ] Know how to contact your local Security Operations Center (SOC) or IT Helpdesk.
* [ ] Immediately report suspicious emails, unexpected account lockouts, or lost devices.
* [ ] Never share your password, PIN, or MFA codes with anyone—including IT support staff.
